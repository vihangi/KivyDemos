# Kivy Demos — CP1404

A collection of Python/Kivy demo projects covering layouts, widgets, graphics, animation, and MVC patterns. Written as part of CP1404 coursework at James Cook University.

---

## demos

| File | What it shows |
|---|---|
| `hello_world.py` | Minimal Kivy app |
| `hello_kv.py` | Basic `.kv` file usage |
| `label_demo.py` | Label widget |
| `button_event_demo.py` | Button events and callbacks |
| `box_layout_demo.py` | BoxLayout |
| `grid_layout_demo.py` | GridLayout |
| `float_layout_demo.py` | FloatLayout |
| `anchor_layout_demo.py` | AnchorLayout |
| `size_and_position_demo.py` | Widget sizing and positioning |
| `dynamic_widgets.py` | Adding/removing widgets at runtime |
| `spinner_demo.py` | Spinner (dropdown) widget |
| `popup_demo.py` | Popup dialogs |
| `hints_demo.py` | Input hints |
| `id_demo.py` | Referencing widgets by ID in `.kv` |
| `clock_demo.py` / `clock_demo2.py` | Kivy Clock for scheduled/repeating events |
| `simple_animation_demo.py` | Basic animation |
| `basic_graphics_demo.py` | Canvas drawing |
| `mouse_drawing.py` | Mouse/touch drawing |
| `falling_drawing.py` | Animated drawing |
| `convert_m_to_km.py` | Simple unit converter app |
| `squaring.py` | Number squaring app |
| `quick_sum_app.py` | Quick sum calculator |
| `mvc_demo.py` | MVC pattern in Kivy |
| `board_game.py` | Board game base |
| `game_v1.py` / `game_v2.py` | Kivy game — two iterations |
| `play_game_console.py` | Console version of the game |
